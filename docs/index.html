Qué es Flowxy Translator

Convierte videos de YouTube — o archivos locales — en material de estudio interactivo. Descarga, transcribe y traduce con GPU, y entrega dos salidas: un reproductor web con subtítulos sincronizados palabra a palabra, y un MP4 con subtítulos quemados que siguen las reglas de la industria del subtitulado.

Está pensado para desarrolladores que aprenden inglés técnico leyendo código mientras escuchan al autor. Todo corre 100% en local: los modelos viven en tu disco; lo único que toca la red es la descarga del video y el doblaje TTS opcional.

Quickstart

Requisitos: Python 3.11+, FFmpeg 6+, y opcionalmente una GPU NVIDIA con CUDA 12.1 (sin GPU funciona en CPU, más lento). Los modelos (~4 GB) se descargan solos la primera vez.

# 1 · Clonar y crear entorno
git clone https://github.com/floowxy/flowxy-translator.git
cd flowxy-translator
python3 -m venv .venv
source .venv/bin/activate        # fish: source .venv/bin/activate.fish

# 2 · Dependencias
pip install -r requirements.txt

# 3 · Verificar GPU (opcional)
python -c "import torch; print('CUDA:', torch.cuda.is_available())"

# 4 · Arrancar
uvicorn backend.main:app --port 9000 --reload

Abre http://localhost:9000. El frontend compilado ya está incluido en el repo — Node solo hace falta si vas a modificar la interfaz (cd frontend && npm run dev levanta Vite en :5173 con proxy al backend).

Puerto 9000 a propósito. El 8000 suele estar ocupado por otros servicios locales. Se cambia en backend/config.py → SERVER_PORT.

Arquitectura

Pipeline de procesamiento

Backend FastAPI completamente asíncrono: todo el trabajo pesado (yt-dlp, Whisper, NLLB, FFmpeg, uploads) corre en asyncio.to_thread y nada bloquea el event loop. Cada etapa persiste su resultado en caché antes de pasar a la siguiente.

▼

Descarga / Upload

yt-dlp para YouTube (video individual, no playlists) o subida directa. Detecta cookies.txt automáticamente si YouTube bloquea.

downloads/{id}_video.webm
W

Whisper medium — transcripción

Beam 5, float16, timestamps por palabra. Filtrado de segmentos sin habla con los parámetros nativos de openai-whisper.

word_timestamps=True · no_speech_threshold=0.6 · compression_ratio=2.4
N

NLLB-200 1.3B — traducción con contexto

El DP grouper agrupa segmentos en oraciones completas y traduce con memoria del grupo anterior. Post-procesado de artefactos.

beam=5 · repetition_penalty=1.1 · no_repeat_ngram=4 · float16
▶

Salidas

Reproductor con word highlighting · MP4 con cues alineados al habla (FFmpeg) · SRT / VTT / JSON / TXT · doblaje Edge-TTS opcional.

exports/{id}_subtitulado.mp4 · {id}_es.srt · …
05
Arquitectura

Traducción con contexto — DP grouper

Traducir subtítulo a subtítulo destroza la calidad: Whisper corta el habla en trozos de ~5 s que rara vez son oraciones completas. El DP grouper (nllb_engine.py) agrupa los segmentos en unidades semánticas antes de traducir, con cuatro señales de cierre de grupo:

SeñalRegla
Oración completaEl texto termina en .!?
Límite del modeloEl grupo acumula 60 palabras (evita truncado de NLLB)
Nuevo pensamientoEl siguiente segmento abre con conector: "However,", "But ", "Now "…
Pausa naturalSilencio ≥ 0.5 s entre segmentos según timestamps

Cada grupo se traduce como texto unificado, y el texto del grupo anterior entra como contexto inter-grupo — pronombres, referencias y continuidad del discurso se resuelven bien. Un post-procesado limpia los artefactos típicos de NLLB ("hola ." → "hola.", artículos duplicados, espacios múltiples).

El resultado no es literal: NLLB reorganiza frases y adapta expresiones idiomáticas manteniendo el tono técnico.

Original:  "I'm gonna grab a bite before we dive into the code"
Literal:   "Voy a agarrar un mordisco antes de que nos sumerjamos en el código"
NLLB:      "Voy a comer algo antes de meternos con el código"
Modo rápido: NLLB_CONTEXT_AWARE = False desactiva la agrupación y traduce en batch puro de 16 segmentos — más veloz, menos coherencia.
06
Arquitectura

Subtítulos alineados al habla

El problema clásico del subtitulado automático traducido: frases cortadas a la mitad, muros de texto, y desfase con lo que el hablante está diciendo. build_translated_cues() (srt_exporter.py) reconstruye los cues desde cero en tres pasos:

  1. División por frases completas. La traducción del grupo se corta por oraciones (.!?…); las largas se parten balanceadas con preferencia por comas — nunca a mitad de sintagma, nunca a mitad de palabra.
  2. Anclado al habla real. Cada cue recibe el intervalo temporal de las palabras fuente que le corresponden, interpolando por posición proporcional de caracteres sobre los word timestamps de Whisper. El subtítulo aparece mientras el hablante dice esa parte.
  3. Pase de legibilidad. Duración mínima garantizada, extensión hacia los silencios cuando hay mucho texto, cierre de micro-huecos para evitar parpadeo, y cero solapes.

Este sistema alimenta el video quemado, el SRT descargable y el VTT. Si un caché antiguo no trae word timestamps, degrada a interpolación lineal sin romperse.

Límite conocido: cuando NLLB reordena mucho una oración larga, el subtítulo puede adelantarse o atrasarse ~1 frase respecto al audio. Es inherente a alinear una traducción reordenada con el habla original.
07
Arquitectura

Gestión de VRAM — offload automático

Con 8 GB de VRAM (RTX 4060 Ti), Whisper medium (~1.5 GB) y NLLB 1.3B (~2.6 GB) se alternan: al usar uno, el otro se mueve a CPU y se limpia la caché CUDA. Tres piezas lo hacen seguro:

  • Precarga en RAM — al arrancar, ambos modelos se cargan en CPU (preload_to_cpu). El primer request no paga cold-start de disco.
  • gpu_lock — mutex async compartido entre todos los endpoints REST y el WebSocket. Serializa el acceso a GPU: dos requests concurrentes jamás compiten por VRAM.
  • Revalidación de caché tras el lock — si dos requests idénticos llegan a la vez, el segundo encuentra el resultado ya cacheado al obtener el lock y no repite la inferencia.
VRAM 8 GB          [Transcripción]          [Traducción]
Whisper            GPU  ──────────────────▶  CPU
NLLB               CPU  ──────────────────▶  GPU
                        torch.cuda.empty_cache() en cada cambio

CapaDóndeQué guarda
RAMdicts LRU, 20 entradas c/uTranscripciones y traducciones de la sesión activa
Discodownloads/{stem}_transcription.json

Todos los endpoints siguen el patrón memoria → disco: si el resultado existe en cualquier capa, se reutiliza. Repetir un paso cuesta <1 s, y el historial restaura sesiones completas desde disco. DELETE /api/cache/translation/{file} fuerza una re-traducción limpia.

Configuración — backend/config.py

# ── Modelos ──────────────────────────────────────────────
WHISPER_MODEL_SIZE = "medium"   # tiny | base | small | medium | large-v3
NLLB_MODEL_SIZE    = "1.3B"     # "600M" | "1.3B"
COMPUTE_TYPE       = "float16"
DEVICE             = "auto"     # "auto" | "cuda" | "cpu"

# ── Whisper ──────────────────────────────────────────────
WHISPER_BEAM_SIZE                   = 5
WHISPER_NO_SPEECH_THRESHOLD         = 0.6   # descarta segmentos sin habla
WHISPER_COMPRESSION_RATIO_THRESHOLD = 2.4   # descarta segmentos "garbage"

# ── NLLB ─────────────────────────────────────────────────
NLLB_BEAM_SIZE          = 5
NLLB_REPETITION_PENALTY = 1.1
NLLB_NO_REPEAT_NGRAM    = 4
NLLB_CONTEXT_AWARE      = True   # DP grouper + memoria inter-grupo

# ── Subtítulos ───────────────────────────────────────────
SRT_MAX_CHARS_PER_LINE = 42
SRT_MAX_LINES          = 2

# ── Servidor ─────────────────────────────────────────────
SERVER_PORT  = 9000
CORS_ORIGINS = []   # frontend en el mismo origen — sin cross-origin

GPU pequeña o solo CPU

WHISPER_MODEL_SIZE = "small"    # ~500 MB VRAM
NLLB_MODEL_SIZE    = "600M"     # ~1.2 GB VRAM
COMPUTE_TYPE       = "int8"

Problemas comunes

CUDA no detectado

Verifica el driver con nvidia-smi y reinstala PyTorch con CUDA 12.1:

pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu121
Memoria GPU insuficiente (OOM)

Baja los modelos en config.py: Whisper "small" (~500 MB), NLLB "600M" (~1.2 GB), COMPUTE_TYPE = "int8". El offload automático ya evita el caso más común — ambos modelos en GPU a la vez.

YouTube bloquea la descarga

Exporta las cookies de tu navegador a cookies.txt en la raíz del proyecto. yt-dlp lo detecta automáticamente en cada descarga; ningún endpoint lo expone.

Los subtítulos exportados no coinciden con el audio

Traducción de un caché antiguo sin word timestamps → el sistema degrada a interpolación lineal. Usa «Re-traducir» (o DELETE /api/cache/translation/{file}) para regenerar los datos completos.

El video no se reproduce en el player

El reproductor necesita el video completo, no solo el audio. Vuelve a descargar con «Descargar VIDEO COMPLETO» activo.

Puerto 9000 en uso 
lsof -i :9000 && kill -9 $(lsof -ti:9000)   # Linux/macOS

O cambia SERVER_PORT en backend/config.py.

Primera ejecución muy lenta

Los modelos se descargan una sola vez: Whisper medium (~1.5 GB) y NLLB 1.3B (~2.6 GB) en models/. Después se precargan en RAM al arrancar — el primer request ya no paga cold-start.
